# Эмулятор командной оболочки ОС

Учебный проект по дисциплине «Конфигурационное управление»,
вариант №14, группа ИКБО-41-25, РТУ МИРЭА.

## Общее описание

Приложение имитирует работу в командной строке UNIX-подобной ОС.
Интерфейс графический, на `tkinter`: одно текстовое поле работает и на
ввод, и на вывод. Так получается диалог с пользователем. Заголовок окна
содержит имя VFS.

Сейчас сделан **Этап 1 «REPL»**. Команды `ls` и `cd` пока заглушки:
выводят своё имя и аргументы. Разбор строки и раскрытие переменных
окружения уже работают.

Весь код лежит в `src/main.py`, тесты в `tests/test_smoke.py`,
запуск через `run.sh`.

## Функции

| Функция | Назначение |
| --- | --- |
| `expand_vars(token)` | Раскрывает `$VAR` и `${VAR}` значениями переменных окружения ОС |
| `parse_line(line)` | Разбивает строку на токены и раскрывает в них переменные |
| `has_invalid_args(name, args)` | Проверяет допустимое число аргументов |
| `format_stub(name, args)` | Формирует вывод команды-заглушки |
| `App` | Окно эмулятора, наследник `tk.Tk` |
| `App.on_enter(event)` | Обрабатывает нажатие Enter |
| `App._execute(line)` | Разбирает и выполняет одну команду |
| `main()` | Точка входа |

Разбор идёт в два шага: `shlex` разбивает строку на токены с учётом
кавычек, затем в каждом токене раскрываются переменные окружения.
Раскрытие идёт именно **после** разбиения, поэтому значение
с пробелами остаётся одним аргументом, как в настоящей оболочке.
Неизвестная переменная раскрывается в пустую строку, как в `bash`.

## Настройки

Именованные константы в начале `src/main.py`.

| Константа | Значение | Назначение |
| --- | --- | --- |
| `VFS_NAME` | `VFS` | Имя VFS в заголовке окна |
| `WINDOW_SIZE` | `600x400` | Размер окна |
| `PROMPT` | `$ ` | Приглашение ввода |
| `FONT_NAME`, `FONT_SIZE` | `Menlo`, `10` | Шрифт терминала |
| `BACKGROUND_COLOR`, `FOREGROUND_COLOR` | `black`, `lime` | Цвета |
| `STUB_COMMANDS` | `ls`, `cd` | Команды-заглушки |
| `MAX_ARGS` | `cd`: 1, `exit`: 0 | Ограничения на аргументы |

## Команды

| Команда | Поведение на Этапе 1 |
| --- | --- |
| `ls [аргументы]` | Выводит своё имя и аргументы |
| `cd [путь]` | Выводит имя и путь, не более одного |
| `exit` | Завершает работу, аргументов не принимает |

Сообщения об ошибках: `Ошибка разбора: незакрытая кавычка`,
`Ошибка: неверные аргументы команды <имя>`,
`Неизвестная команда: <имя>`.

## Сборка и запуск

Сборка не требуется. Нужен Python 3.9+ с поддержкой `tkinter`.

```sh
./run.sh                                               # приложение
PYTHONPATH=src python3 -m unittest discover -s tests   # тесты
```

Если `tkinter` не найден, поставьте его: `brew install python-tk@3.14`.
