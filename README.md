# Эмулятор командной оболочки ОС

Учебный проект по дисциплине «Конфигурационное управление»,
вариант №14, группа ИКБО-41-25, РТУ МИРЭА.

## Общее описание

Приложение имитирует работу в командной строке UNIX-подобной ОС.
Интерфейс графический, на `tkinter`: одно текстовое поле работает и на
ввод, и на вывод. Так получается диалог с пользователем. Заголовок окна
содержит имя VFS.

Сделаны **Этап 1 «REPL»** и **Этап 2 «Конфигурация»**. Команды `ls`
и `cd` пока заглушки: выводят своё имя и аргументы. Работают разбор
строки, раскрытие переменных окружения, параметры командной строки,
конфигурационный файл и стартовые скрипты.

Код разложен по трём модулям: `src/config.py` отвечает за параметры
запуска, `src/emulator.py` за разбор строки и выполнение команд,
`src/main.py` за графический интерфейс. Только последний импортирует
`tkinter`, поэтому тесты не требуют графического окружения.

## Параметры командной строки

| Параметр | Назначение |
| --- | --- |
| `--vfs ПУТЬ` | Путь к физическому расположению VFS |
| `--startup ПУТЬ` | Путь к стартовому скрипту эмулятора |
| `--config ПУТЬ` | Путь к конфигурационному файлу TOML |

При запуске эмулятор печатает отладочный вывод всех заданных
параметров, указывая источник каждого значения:

```
Параметры запуска:
  конфигурационный файл: config/default.toml
  путь к VFS: data/vfs_cli [командная строка]
  стартовый скрипт: startup/stage2.txt [конфигурационный файл]
```

Вывод идёт и в окно, и в стандартный поток, чтобы его можно было
перенаправить в файл.

## Конфигурационный файл

Формат TOML, два ключа:

```toml
vfs_path = "data/vfs"
startup_path = "startup/stage2.txt"
```

**Приоритет:** значение из командной строки важнее значения из файла.
Если параметр задан в обоих местах, берётся тот, что из строки.

Недоступный файл, повреждённый TOML и неизвестный ключ дают сообщение
об ошибке и код возврата 1. Примеры лежат в `config/`: рабочие
`default.toml` и `vfs_only.toml`, а также заведомо испорченные
`broken.toml` и `unknown_key.toml`.

## Стартовый скрипт

Текстовый файл с командами эмулятора, по одной на строку. Пустые строки
и строки, начинающиеся с решётки, пропускаются.

Команды выполняются последовательно. **Ошибочная строка пропускается:**
в окно выводится сообщение с её номером, выполнение продолжается
со следующей команды. На экране видно и ввод, и вывод, так что
получается тот же диалог, что и при ручной работе. Ввод подсвечивается
синим, ошибки красным.

Если скрипт заканчивается командой `exit`, окно закрывается. Иначе
эмулятор переходит в интерактивный режим.

Примеры в `startup/`: `stage2.txt` со всеми режимами команд,
`errors.txt` только из ошибочных строк, `interactive.txt` без `exit`.

## Функции

### `src/config.py`

| Функция | Назначение |
| --- | --- |
| `build_parser()` | Описывает параметры командной строки |
| `read_config_file(path)` | Читает и проверяет файл TOML |
| `pick_value(cli, file)` | Реализует приоритет командной строки |
| `load_config(argv)` | Собирает итоговую конфигурацию |
| `describe(config)` | Формирует отладочный вывод параметров |

### `src/emulator.py`

| Функция | Назначение |
| --- | --- |
| `expand_vars(token)` | Раскрывает `$VAR` и `${VAR}` |
| `parse_line(line)` | Разбивает строку на токены и раскрывает переменные |
| `has_invalid_args(name, args)` | Проверяет допустимое число аргументов |
| `format_stub(name, args)` | Формирует вывод команды-заглушки |
| `execute_line(line)` | Выполняет одну команду |
| `run_script(path)` | Выполняет стартовый скрипт, возвращая протокол |

### `src/main.py`

| Элемент | Назначение |
| --- | --- |
| `App` | Окно эмулятора, наследник `tk.Tk` |
| `App.on_enter(event)` | Обрабатывает нажатие Enter |
| `App.replay(events)` | Отображает протокол стартового скрипта |
| `main(argv)` | Точка входа |

Разбор строки идёт в два шага: `shlex` разбивает её на токены с учётом
кавычек, затем в каждом токене раскрываются переменные окружения.
Раскрытие идёт именно **после** разбиения, поэтому значение
с пробелами остаётся одним аргументом, как в настоящей оболочке.
Неизвестная переменная раскрывается в пустую строку, как в `bash`.

## Настройки

Именованные константы в начале модулей.

| Константа | Модуль | Назначение |
| --- | --- | --- |
| `KNOWN_KEYS` | `config.py` | Допустимые ключи файла TOML |
| `PROMPT` | `emulator.py` | Приглашение ввода |
| `STUB_COMMANDS` | `emulator.py` | Команды-заглушки |
| `MAX_ARGS` | `emulator.py` | Ограничения на число аргументов |
| `VFS_NAME` | `main.py` | Имя VFS в заголовке окна |
| `WINDOW_SIZE` | `main.py` | Размер окна |
| `FONT_NAME`, `FONT_SIZE` | `main.py` | Шрифт терминала |
| `ERROR_COLOR`, `ECHO_COLOR` | `main.py` | Цвета ошибок и ввода |

## Команды

| Команда | Поведение |
| --- | --- |
| `ls [аргументы]` | Заглушка: выводит своё имя и аргументы |
| `cd [путь]` | Заглушка: выводит имя и путь, не более одного |
| `exit` | Завершает работу, аргументов не принимает |

Сообщения об ошибках: `незакрытая кавычка`,
`неверные аргументы команды <имя>`, `неизвестная команда: <имя>`.
В скрипте к ним добавляется номер строки.

## Сборка и запуск

Сборка не требуется. Нужен **Python 3.11 или новее** из-за `tomllib`,
который появился в стандартной библиотеке именно в 3.11, и поддержка
`tkinter`.

Проверка окружения:

```sh
python3 --version
python3 -c "import tkinter, tomllib"
```

Запуск:

```sh
./run.sh                                      # без параметров
./run.sh run --config config/default.toml     # всё из конфигурации
./run.sh run --vfs data/vfs --startup startup/stage2.txt
./run.sh test                                 # тесты
```

Интерпретатор переопределяется переменной `PYTHON`:

```sh
PYTHON=/opt/homebrew/bin/python3.14 ./run.sh
```

Если `tkinter` не найден, поставьте его: `brew install python-tk@3.14`.

## Примеры использования

Команды-заглушки и кавычки:

```
$ ls
ls
$ ls -l /home
ls -l /home
$ cd "my folder"
cd my folder
```

Раскрытие переменных окружения:

```
$ cd $HOME
cd /Users/user
$ ls ${HOME}/Documents
ls /Users/user/Documents
```

Обработка ошибок:

```
$ cd "unclosed
Ошибка: незакрытая кавычка
$ cd /home /tmp
Ошибка: неверные аргументы команды cd
$ exit now
Ошибка: неверные аргументы команды exit
$ pwd
Ошибка: неизвестная команда: pwd
```

Выполнение стартового скрипта, ошибочные строки пропущены:

```
$ ls
ls
$ cd "незакрытая кавычка
Ошибка: ошибка в строке 18: незакрытая кавычка
$ cd /home /tmp
Ошибка: ошибка в строке 19: неверные аргументы команды cd
$ ls итог
ls итог
$ exit
```

## Известные ограничения

Одинарные кавычки не подавляют раскрытие переменных, в отличие
от `bash`.
